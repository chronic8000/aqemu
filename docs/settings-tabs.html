Settings tab map

Docs v1 Last updated 31 October 2026. These guides are a first version and will be updated.

Select a VM in the list on the left, and its settings appear in tabs on the right. When you change something, click Apply to save it, or Discard Changes to undo it.

AQEMU-wide settings (not per VM) are in File → Preferences…. See Preferences.

Advanced Extra options for power users

Some guests show an extra panel:

  • Windows 11 ARM: Apply VirtIO defaults and a Mode chooser (Install Windows / First boot / Normal / OOBE). See Windows 11 on ARM.
  • Intel macOS (experimental): OpenCore, installer image, Apple SMC OSK (AQEMU never pre-fills this), Launch via WSL/KVM and AMD GPU passthrough. See macOS.
  • Apple SoC / iOS (experimental): DeviceTree, kernel and boot arguments. See iOS (Apple SoC).

Snapshot mode throws away every change when the VM stops. See Snapshots.
